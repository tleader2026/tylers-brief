# Header design

Page identities use the existing tan treatment. Headers introducing a particular sub-tab use the existing blue panel treatment. Color describes scope, not evidence status.

Use `site-header site-header--page` with `data-header-scope="page"` for an introduction retained across sub-tabs. Use `site-header site-header--tab` with `data-header-scope="tab"` when the introduction changes with or belongs to a selected sub-tab. Mark the actual introductory container, not the dashboard wrapper or metric cards. Reused dashboards choose scope from their context (Capabilities versus the Economy/Governance sub-tabs, Robotics versus Labor & Productivity).

The shared page title above navigation stays tan. Views without an additional introduction need no duplicate header. Preserve existing content, source dates, filters and source-health controls. Headers use the shared 32px desktop / 28px mobile title scale and 14px supporting text. The large population remainder metric remains a separate exception.

Examples: Drug Discovery, Supply Chains and the Capabilities observatory have persistent tan introductions. Utilities, Population Health, Governance and Progress have changing blue introductions. Labor Careers, Housing Smart Upgrades and Companies AI Growth introduce specific sub-tabs in blue.
